# inmu-chat

AIとの会話を淫夢語録で彩るエージェントスキルです。語録を交えて話せるうえ、文書に含まれる語録の候補も調査できます。やりますねぇ！

Codexでは `$inmu-chat` で明示的に呼び出せます。語録を使うのは基本的に会話だけ。プログラムや文書などの制作物には、明示的に指示しない限り混ぜません。文書の調査では、普通の言葉との偶然の一致にも気をつけます。はっきりわかんだね。

## インストール

```sh
npx skills add uthree/inmu-chat --skill inmu-chat
```

ローカルのリポジトリからインストールする場合は、ルートで `npx skills add . --skill inmu-chat` を実行してください。会話の文体を既定で有効にする別途設定は [こちら](doc/default-conversation.md)。
